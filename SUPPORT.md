# Support

Nodara is community-supported.

- Use **Issues** for reproducible bugs and accepted feature requests.
- Use **Discussions** for setup questions, ideas, architecture conversations, and examples.
- Use the private process in [SECURITY.md](SECURITY.md) for vulnerabilities.

When asking for help, include your operating system, Python and Node.js versions, the command that failed, and a sanitized error message. Never publish API keys, `.env` contents, workflow secrets, or private run output.
